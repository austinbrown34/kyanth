Against the eight-row wall

  • Brand top-left, progress top-right. The lockup sits where the sidebar puts it in Settings — same size, same gradients, full strength. The ring moved to the opposite end of the headline row because it is a status readout, not part of the identity, and the window title is gone since the lockup already names the app.
  • Three phases, three boxes. Permissions, hardware, verification — the grouping tells you which failures you can fix and which ones only System Settings can. It is the same grouped-box shape Settings uses, so the two windows read as one app.
  • Progress is explicit. A ring and an n/8 count replace implicit progress; the headline says what is left, not what the window is called.
  • One obvious next action. The blocking step owns the primary button, its box carries a blue edge, and it is the only tinted row. The footer keeps one primary and one quiet escape instead of four competing buttons.
  • Satisfied steps went slate; only the live step is blue. Seven green ticks shout, and this window's own argument is that green permissions are not proof.
  • Step 8 still gates completion. Finish stays disabled until a held key produces text.

Try it: Open System Settings grants the permission the way the real one-second re-poll would, then Hold to talk (or hold the ⌥ key) to run the verification.
