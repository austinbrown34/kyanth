What moved and why

  • The status line became a header, not a row. It no longer truncates to the menu width, it carries the live input meter, and it spells the chord out in key caps instead of prose — so the one thing a user forgets is the one thing the menu leads with.
  • Five diagnostics went behind Advanced. Edit Config, Reload Config, Restart Model Server, Open Log and Check for Updates are still one hover away; they no longer sit between Enabled and Quit.
  • Recent got a preview. Two lines and a timestamp per entry instead of a truncated single line, because a transcription is usually a sentence, not a label.
  • Sound cues and Open at Login moved to Settings → General. They are preferences set once, not actions taken daily.
  • Six rows, three groups, one destructive action isolated at the bottom.
